## v10.9 — 固定目标版 (2026-11-24)
目标值来源：用户 2026-11-08 定值（49岁、158cm、44.0kg、实测 BMR 1070 kcal）。
- **目标改为固定值**：训练日 1700 kcal / 休息日 1500 kcal；蛋白 80g（区间 70–90g）、碳水 200g（总量，纤维计入其中）、脂肪 50g（胆囊原因封顶）、纤维 25g。`dailyTarget()` 不再用体重系数推算；上方「体型目标 / 宏量流派 / BMR / 活动系数」控件保留展示与参考，不再改变目标。默认基线更新为 49岁、44.0kg、体脂 26.4%、手动 BMR 1070。
- **食物库新增 fiber 字段（每 100g）**：62 种原有食物全部补上纤维值；热量公式改为 蛋白×4 + 净碳水×4 + 脂肪×9 + 纤维×2。纤维值来源以 USDA FoodData Central SR Legacy 为主，少数按中国食物成分表；**估算值仅两处**：c30 普通面条熟 纤维 1.8（按鸡蛋面 USDA 值估算）、c31 肌肉小饺 纤维 2.0（包装未标示，按同类冷冻鸡肉饺 1.4–1.6g、魔芋/燕麦皮略高估算），均已在食物 note 里注明“纤维估算”。
- **新增 4 种食物**：p21 蛋黄（USDA 生蛋黄）、p22 牛奶（全脂，USDA）、c31 肌肉小饺（野人日记鸡肉味；包装标示蛋白 6.6 / 脂肪 1.9 / 碳水 17 / 钠 484mg 每 100g，纤维为估算，勿蘸酱油）、f14 南瓜籽仁（USDA 干籽仁）。
- **30 天菜单全部重新配平**（只调克数、不换菜名、不改菜式结构）：30 天总量全部落在蛋白 70–90g、碳水 190–210g、脂肪 45–55g、纤维 ≥20g、热量 1500–1700 kcal；实测区间为蛋白 79.7–88.5g、碳水 190.0–200.2g、脂肪 48.7–50.2g、纤维 24.4–36.7g、热量 1588–1628 kcal（按页面内热量公式重算）。为补足碳水，**每一天第一餐都加了燕麦干 80g**（干重，约一碗半燕麦粥）；第 5、10、11、27 天第二餐新加白米饭 180g，第 7 天白米饭 130g→219g、第 23 天 150g→275g。各天标题与备注沿用 v10.8 文案（菜式描述，未随新目标重写）。
- **取舍说明**：蛋白目标 80g 下，谷物/蔬菜/豆类自带约 30g 植物蛋白，主菜蛋白只能配到约 50g/餐（多为下限）；若想主菜恢复 70g 以上，总蛋白会超过 90g 上限——需先放宽蛋白目标再重配。
- 界面：账本增加膳食纤维卡片（目标 25g）；菜单总计、每餐小计、导出表、本餐累计、快速录入预览均增加纤维行；食物选择器显示每 100g 纤维；自定义食物可填纤维。localStorage 键改为 `bio_hacker_os_v10_9_user_data`（旧版保存数据不会覆盖新版食物库）。
