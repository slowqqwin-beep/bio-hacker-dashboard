# Bio-Hacker 代谢监控中心 v10.4

极客风格的营养代谢仪表盘，面向偏瘦增肌、地中海饮食和控糖质量管理。

## 本版更新

- 支持根据身高、体重、年龄、性别自动估算 BMR
- 支持手动覆盖 BMR，例如录入体脂秤测得的 1104 kcal
- 以 BMR → 活动系数 → TDEE → 训练/休息日盈余 计算目标热量
- 将单点目标升级为目标区间：热量、碳水、蛋白质、脂肪都有上下限
- 主食矩阵生成器会为每个食材计算“建议克数”和“可用范围”
- 食材范围会同时考虑本餐宏量上下限，避免总量低于下限或超过上限
- 食物库加入常见食材，例如鸡蛋（全蛋）、鸡胸、虾、三文鱼、米饭、红薯、希腊酸奶、橄榄油等

## 使用

直接用浏览器打开 `index.html` 即可，无需构建。

## 技术栈

- Vue 3 (CDN)
- TailwindCSS (CDN)
- 纯前端，零依赖部署
